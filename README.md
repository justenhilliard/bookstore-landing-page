# Tree Stump Bookstore

Tree Stump Bookstore is just a bookstore landing page. The project was built to practice semantic HTML, external CSS styling, layout design, cards, buttons, and visual branding.

## Project Overview

The site is designed to feel warm, inviting, and slightly enchanted. It includes sections that introduce the bookstore, highlight featured shelves, showcase staff picks, describe events, and invite visitors to stay connected.

## Features

- Semantic HTML structure
- External CSS styling
- Hero section
- Navigation bar with section links
- Styled content cards using `article`
- Custom buttons and hover effects
- Bookstore-themed color palette
- Event card with image
- Footer section

## Sections Included

- Hero / Welcome section
- Our Story
- Featured Shelves
- From the Shopkeeper's Shelf
- Step Into the Story
- Gather Beneath the Lanterns
- Find Your Way to the Stump
- Join the Reading Circle
- Footer

## Technologies Used

- HTML5
- CSS3

## Project Goals

This project was created to practice:

- building a multi-section landing page
- using semantic HTML elements like `header`, `nav`, `main`, `section`, `article`, and `footer`
- linking an external stylesheet
- styling layouts with CSS
- creating card-style content sections
- improving page design with spacing, colors, buttons, and images
